# Дагдел · модули витрины на Next.js

В этом репозитории сохранены девять исходных модулей витрины «Дагестанские деликатесы». В архив входят модули корзины, поиска и каталога, компоненты карточки и галереи товара. Для отдельного запуска модулей нужны данные каталога и остальная часть приложения.
